# 前端部署文档

前端采用纯静态部署：在本地使用 npm 构建，然后把 `build/client` 上传到服务器。服务器不需要安装 Node.js，也不需要启动前端服务。

本地需要 Node.js `22.23.0` 或更高版本和 npm。本文假设服务器已配置好 Web 服务，站点目录为 `/var/www/flow-talk-web`。

## 1. 本地构建

```bash
cd flow-talk-web
npm ci
npm run typecheck
npm run build
```

构建产物：

```text
build/client/
```

## 2. 使用 PM2

```bash
npm install pm2 -g
```

进入项目下启动

```bash
# 方式1 直接启动
pm2 start "npm run start" --name flow-talk-web

# 设置开机自启
pm2 startup
pm2 save

pm2 list                # 查看运行程序
pm2 restart flow-talk-web # 重启
pm2 stop flow-talk-web # 暂停
pm2 logs flow-talk-web # 看日志
```
